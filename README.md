# Estoque-Inteligente
Sistema inteligente de localização de calçados que integra Alexa, MQTT e ESP32 para auxiliar funcionários na consulta e localização rápida de produtos em uma loja. A solução utiliza uma Skill personalizada da Alexa, um backend em Python, banco de dados MariaDB, broker MQTT e um ESP32 responsável por indicar a localização do item por meio de LEDs.
